## Publish from this Git repository

This folder already contains two commits on the `main` branch. Create an empty public GitHub repository named `lab4`, then in this folder run:

```bash
git remote add origin https://github.com/YOUR-USERNAME/lab4.git
git push -u origin main
```

In the repository, open **Settings → Pages**, choose **Deploy from a branch → main → /(root)**, and save. The Pages URL normally takes the form `https://YOUR-USERNAME.github.io/lab4/`. Open it and check that the stylesheet and image load before submitting the actual link along with the Figma file as instructed in Quercus.

The four Register buttons are visual placeholders. This lab grades responsive layout; registration behaviour is outside its stated requirements.
